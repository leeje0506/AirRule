# 월 정산

1. 서버(studio 컨테이너)에서 데이터 추출 — 교정 최초 완료가 그 달인 회차 + 그 회차의 싱크(완료일 무관)
   ```bash
   ./정산_쿼리.sh 2026-10 > 정산_202610.tsv
   ```
2. 워크북 틀에 채우기 (구글 시트 틀 형식, 엑셀에서도 값 보임)
   ```bash
   python3 settlement_workbook.py '(수정중)정산_워크북_틀_v2.7.xlsx' 정산_202610.tsv 2026-10 정산_워크북_202610.xlsx
   ```
3. 단순 표 형식이 필요하면 `python3 settlement_xlsx.py 정산_202610.tsv 정산_202610.xlsx 10월`

openpyxl 필요(배포 의존성 아님 — 로컬 전용). 틀·결과 엑셀은 작업자 이름이 들어 있어 커밋하지 않는다(docs/ 는 gitignore).
